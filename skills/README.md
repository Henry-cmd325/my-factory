# Factory skills

Skills tell coding agents how code must be written in a factory project. Each skill is a folder with a `SKILL.md`.

No skills are written yet. They will come out of the first experiment ([inventory-lab](https://github.com/Henry-cmd325/inventory-lab)). Candidate skills, to be confirmed:

| Skill | Covers |
| --- | --- |
| `domain-modeling` | Turning requirements into C# domain classes, with rules as guards |
| `vertical-slice` | Anatomy of a slice on Clean Architecture + VSA |
| `fastsharp` | Modules and `IEndpoint` with FastSharp, AOT-safe |
| `property-testing` | Writing property-based tests for a slice's rules |
| `mutation-testing` | Running Stryker.NET and fixing surviving mutants |
| `ui-testing` | Exploring the UI as an agent and turning findings into Playwright scripts |
| `docker` | Running the app, database and test tiers in Docker |
